## What would you like to do?

- [Find a meeting, map, election, or person](/docs/users/) — learn how to browse and search Civic Pulse, read meeting records, and use the public calendar.
- [Add meeting notes or manage content](/docs/admins/) — follow the admin guide for meetings and other records.
- [Connect an AI assistant](/docs/ai/) — set up ChatGPT, Codex, or another MCP client, find the OpenAI and Pi plugins, and use civic skills.

Browsing public information does not require an account. Editing requires admin access.
