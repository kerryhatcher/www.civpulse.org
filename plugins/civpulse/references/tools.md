# Civic Pulse MCP tools

Generated by `bun run plugin:build` from the server’s actual tool schemas.
There are 99 tools. Consult live tool schemas for parameter types and defaults.

All MCP access requires OAuth. Reads follow the connected account’s visibility.
Account search, promotion, content and image writes require an administrator. The only non-admin write is
`update_my_profile`, which updates the caller’s display name. Use search_users and promote_user_to_admin for explicitly requested account administration.
Auth account provisioning/deletion, demotion, password resets, RLS changes and website deployment are outside this plugin.
